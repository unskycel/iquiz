# Plan: Re-import Network Question Banks with Chapter Names

## Goal
Re-import 3 computer network question bank files, preserving chapter names by prepending them to question content.

## Approach
1. Delete existing 3 "计算机网络" quizzes
2. Modify `scripts/import-network.mjs` to prepend chapter name to question content
3. Re-run the import

## Change in `scripts/import-network.mjs`
In the `flush()` function, prepend chapter name to content:
```js
content: currentChapter ? `【${currentChapter}】${currentContent.trim()}` : currentContent.trim(),
```

This produces:
- `【计算机网络基本概念与历史】世界上第一个计算机网络是ARPANET。（ ）`

## Execution
1. Delete existing quizzes
2. Update script
3. Run import
